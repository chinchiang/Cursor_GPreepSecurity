# CTEM 週期操作

Gartner 的 CTEM 是持續計畫，不是產品。你協助使用者走完**一個週期**並留下可回測的產出。

## 五階段

1. **Scope**：業務結果、資料分級、納入／排除。
2. **Discover**：列舉暴露並去重，記錄來源與時間。
3. **Prioritize**：可利用性、可達性、業務衝擊、情報、修復成本。不要只按 CVSS。若使用本專案權重，標示示範設計。
4. **Validate**：用安全仿真、控制評估或書面證據確認暴露為真。禁止真實 exploit。
5. **Mobilize**：修復、補償、欺騙、阻斷；留下負責人與回測方式。

## 輸入

- 範圍草案或業務服務清單
- 發現來源（掃描、雲端姿勢、身份、供應鏈、人工）
- 既有工單與變更窗口
- 驗證政策（可做／不可做）

## 輸出

每個週期至少產出：

1. 範圍聲明（含排除理由）
2. 暴露表：id、資產、類型、來源、時間、業務服務、狀態
3. 分堆：本週必做／待驗證／可延
4. 驗證紀錄：方法、結果、限制
5. 動員單：動作、3D 類型、負責人、期限、回測
6. 未完成與待驗證來源

## 規則

- 沒有驗證的高分暴露，狀態必須是「待驗證」，不能寫成「已確認可利用」。
- 第三方資產未經授權不得測試。
- 自動化建議必須寫清權限邊界。
