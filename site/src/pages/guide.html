安裝及使用

用上方按鈕切換 ChatGPT、Claude、Grok、GLM、DeepSeek。GLM 與 DeepSeek 沒有原生 SKILL.md，改用系統提示。示範不需要 API 金鑰。請勿把雲端憑證寫進技能檔或本站前端。

所有平台共用的使用順序

  1. 先讀 來源與查證 的限制。
  2. 用合成資料跑 Skills 專區裡對應平台的 GAC 工作流程（ChatGPT／Claude／Grok 為 SKILL.md；GLM／DeepSeek 為系統提示）。
  3. 再進入 CTEM 週期，不要一開始就對生產環境驗證。
  4. 任何分數都加上「本專案示範設計」或改用你們自己的政策。
